# Fonts for the sharing images

Used only when generating the Open Graph images (`opengraph-image.tsx` files); they're never sent to visitors.
The image renderer needs TTF/OTF/WOFF, not the WOFF2 files `next/font` serves, hence these copies.

- `Spectral-SemiBold.ttf`: Spectral by Production Type, from github.com/google/fonts (ofl/spectral)
- `Tangerine-Bold.ttf`: Tangerine by Toshi Omagari, from github.com/google/fonts (ofl/tangerine)

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
